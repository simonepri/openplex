# Notebook Example

An interactive Jupyter notebook demonstrating interactive Python compute, filesystem inspection, and data processing within interactive workspaces using Zasper.

## Running the Notebook

1. Open **Zasper** from the Coder workspace dashboard.
2. In the file browser under `/fs/depot/src/examples/notebook`, click `example.ipynb`.
3. Select the **Python 3** kernel to run and interact with the cells.
